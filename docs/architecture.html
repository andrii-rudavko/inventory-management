VueFrontend

  • src/views/*.vue — Dashboard, Inventory, Orders, Spending, Demand, Backlog, Reports
  • src/components/ — FilterBar, detail modals, LanguageSwitcher, ProfileMenu
  • src/composables/ — useFilters, useAuth, useI18n (Composition API)
  • src/api.js — single fetch client for all backend calls
  • src/locales/ — en.js / ja.js translation strings

PythonBackend

  • server/main.py — FastAPI app, 14 REST endpoints, CORS enabled
  • server/mock_data.py — loads/filters JSON data, Pydantic models
  • /api/inventory, /api/orders — filter by warehouse/category/status/month
  • /api/dashboard/summary, /api/reports/* — aggregated KPIs
  • /api/demand, /api/backlog — unfiltered lists

Data Flow

  • User changes a filter (Time Period / Warehouse / Category / Order Status) in FilterBar.vue
  • Filter state lives in useFilters.js, shared across views
  • Views call api.js, which appends filters as query params
  • FastAPI filters the in-memory JSON data and returns validated Pydantic models
  • Vue stores raw data in refs, derives display values via computed properties

Notes

  • No database — all data is static JSON seeded via generate_data.py
  • i18n supports English/Japanese via useI18n.js
  • App intentionally ships planted bugs (see Reports page) for workshop practice
  • Repo is public — no secrets/credentials should ever be committed
